# MVP brief

## Visual language
- Website: black/white only, technical/minimal UI.
- Wallpaper: user-defined BACKGROUND + PRIMARY colors.
- Minimal grid/technical details, optional.
- Lock Screen only.
- Important content stays below the iOS clock safe zone.

## Wallpaper modules
1. Year progress: OFF / percent / day count.
2. Birthday countdown: OFF / days remaining.
3. Daily object: OFF / Flowers / Animals / Geometry; size S/M/L.
4. Daily motivation: OFF / 60 positive verbs; RU/EN.
5. UI details: ON/OFF.

## Daily libraries
- 60 flowers
- 60 animals
- 60 geometry sprites
- 60 bilingual motivation pairs

## Storage
No user database in MVP. The generated permanent URL contains the settings.
